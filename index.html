Python Diffusers Quickstart 
import torch
from diffusers import CogVideoXPipeline
from diffusers.utils import export_to_video

# Load CogVideoX-2B or 5B
pipe = CogVideoXPipeline.from_pretrained(
    "THUDM/CogVideoX-2b", 
    torch_dtype=torch.float16
)

# Enable memory optimizations
pipe.enable_model_cpu_offload()
pipe.vae.enable_tiling()

prompt = "A cinematic shot of a drone soaring through misty mountain peaks at sunrise, 4k"
video = pipe(
    prompt=prompt,
    num_frames=49,
    guidance_scale=6.0,
    num_inference_steps=50,
).frames[0]

export_to_video(video, "output.mp4", fps=8)
print("Video created successfully: output.mp4")
Local Inference

Run CogVideoX on Your Own Hardware

If you have an NVIDIA GPU (RTX 3060, 3090, 4080, 4090, or A-series), you can run inference locally with maximum privacy and speed.

CogVideoX-2B

~11 GB

Minimum VRAM (with sequential CPU offload)

RTX 3060 / 2080Ti / 4060Ti 16GB

CogVideoX-5B

~18 GB

Minimum VRAM (with CPU offload + tiling)

RTX 3090 / 4090 / A5000

Python Environment

3.10 - 3.12

Recommended Python version with PyTorch CUDA

CUDA 12.1+

Step-by-Step Local Setup

  1. 1. Clone the repository 
    git clone https://github.com/mdsajid-ui/Video-Making.git
cd Video-Making
  2. 2. Create and activate a Python virtual environment (Python 3.10 to 3.12 recommended) 
    python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux / Mac:
source venv/bin/activate
  3. 3. Install PyTorch with CUDA support 
    pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
  4. 4. Install dependencies 
    pip install -r requirements.txt
  5. 5. Run Text-to-Video Generation via CLI 
    python inference/cli_demo.py --prompt "A majestic golden eagle soaring over snowy mountain peaks" --model_path THUDM/CogVideoX-2b --generate_type "t2v"
  6. 6. Launch the Local Gradio Web Demo 
    python inference/gradio_web_demo.py
